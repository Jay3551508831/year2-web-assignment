Academic Background

I am currently studying Business Management and Information Systems (BMIS) and developing my knowledge of web technologies. Through this course, I have learned how static webpages are structured and how client-side code can communicate with a back-end server.

I am interested in how technical systems support business decisions. BMIS gives me a useful balance between understanding users, organising information, and learning how software can solve practical problems.

Interest in Web Development

Web development interests me because it combines programming, design, problem-solving, and user experience. A successful web application is not only functional, but also clear, responsive, and easy for users to understand.

I enjoy building small projects because they make abstract programming ideas easier to understand. This coursework helped me practise turning requirements into pages, layouts, events, and server-side logic.

Skills I Am Practising

  • Writing valid and semantic HTML5 pages
  • Using CSS for layout, colour, spacing, and responsiveness
  • Programming interactive features with JavaScript
  • Building a server with Node.js and Express
  • Using Socket.IO for real-time communication

Future Goals

In the future, I want to improve my ability to design full-stack web applications. I am especially interested in learning how to make web applications more reliable, accessible, and secure.

Connection to This Project

The multiplayer puzzle game in this website allowed me to practise both front-end and back-end development. The client displays the board and handles user interaction, while the server maintains the shared game state and controls the turn order.
